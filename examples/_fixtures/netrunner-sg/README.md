# netrunner-sg (internal test fixture)

**This is an internal test fixture for the tabletop-format platform, not a
game published or hosted by this project.** It exists to stress-test the
platform's schema and tooling (`tools/validate.py`, `tools/render_cards.py`,
`tools/check_deck.py`) against a real, structurally rich trading card game.

## Provenance

- **Rules and card data**: Android: Netrunner / Netrunner, designed by
  Fantasy Flight Games and continued by Null Signal Games (NISEI). All card
  names, card text, flavor, faction names, and game rules are the
  intellectual property of their respective rights holders.
- **Source of the data in this directory**: fetched live from
  [NetrunnerDB](https://netrunnerdb.com/)'s public JSON API
  (`https://raw.githubusercontent.com/NetrunnerDB/netrunner-cards-json/master/pack/sg.json`
  for the 77 System Gateway cards, and
  `https://netrunnerdb.com/api/2.0/public/mwl` for the current banlist), on
  2026-08-16. The card-data repository has no general open-content license
  grant for this material; community availability is not permission to
  republish it as a product.
- **Symbols used by the Forge-original proof frame**: unmodified SVGs from
  Null Signal Games' Visual Assets pack, attributed in
  `assets/nsg-symbols/README.md` under CC BY-ND 4.0. That grant applies only
  to the included symbols, not to card text, official frames, art, or backs.
- **What was ported**: all 77 System Gateway cards (`components/cards.json`,
  `components/printings.json`), the current live "Standard Balance Update
  26.08" banlist entries that touch System Gateway cards
  (`restrictions/standard-2026-08.yaml`), one set record, one format, two
  sample decks, and a condensed rulebook written from general knowledge of
  the published rules (not copied from any single rules document).
- **Completeness**: this is essentially the *entire* System Gateway card
  pool (77/77 cards, matching the real 205-card physical print run once
  per-card quantities are counted) — nothing was skipped or abbreviated for
  space. What is *not* included is anything outside System Gateway: no other
  cycles/packs, no general errata history, and no official rulebook text
  verbatim. The internal private-PnP proof now includes losslessly extracted
  composed faces from the official 2023 PDF. Those flattened faces remain
  rights-holder artwork, not reusable Forge assets or editable source files.
  The ordinary editable fallback deliberately uses an original Forge frame.

## What this fixture is for

Netrunner exercises corners of the format that a simpler original game
(like `examples/ember`) does not: two structurally different deck "sides"
sharing one card pool, influence-based deckbuilding, per-identity minimum
deck sizes, singleton (1-of) cards mixed with 3-of cards in the same set,
a real banlist with live bans, and rules text dense with inline symbols.
See `WHAT-BROKE.md` in this directory for everything that did not fit
cleanly.

## Active Forge-native production kit

`templates/layout.yaml` is the active card-production connection used by the
Forge editor, visual diffs, PNG renderer, and print pipeline. It implements
separate identity, ICE, agenda, and standard portrait families; selects a
faction palette from semantic card data; renders official glyph assets from
the game manifest; and exposes every editable number and text field as a live
region. The official PnP image is cropped to the illustration window only.
The title, frame, type line, rules, flavor, statistics, influence track, and
footer are regenerated by Forge and therefore respond to any card-data edit.

The kit uses locally bundled open fonts and is deliberately a community
reconstruction rather than a claim to NSG's original Affinity source files.
It follows Netrunner's information hierarchy closely enough to make the full
77-card System Gateway pool a realistic production stress test while retaining
an independently authored frame. `source-overlay.yaml` and `production.json`
are disabled in normal rendering so they cannot silently replace this editable
path with a flattened source face.

## Legacy private source-overlay proof of concept

`fmt import pnp-faces <official.pdf> examples/_fixtures/netrunner-sg` crops
the official 3x3 print sheets in collector-number order into local `scan`
references. The PDF represents an older semantic revision than today's card
JSON, so `templates/source-baseline-data.json` pins the historical data visible
on those faces instead of pretending that the raster already contains later
errata.

`templates/source-profile-families.yaml` contains reviewed geometry and donor
maps for every structural family. The generator expands it into card-specific
profiles for all 77 cards, and the compiler produces `templates/source-overlay.yaml`.
Supported numeric edits use native-pixel donor patches prepared for that exact
card family, field, and value; the identity statistics use bounded live numeric
regions; and ordinary-card influence uses declared five-socket pip tracks built
from inspected empty/filled source pixels. Bounded text fields use recovered
clean regions, declared fonts, and the official NSG symbols. The grid, live
editor, visual diff, PNG renderer, and PnP PDF can be pointed at that same
legacy render path for finite-state audits; normal Forge rendering leaves it
disabled in favor of `layout.yaml`.

This is card-complete for bounded edits to the mapped fields in System Gateway.
The current coverage audit reports 28 exact cards, 49 mapped overlays, and zero
fallbacks for current data. Every original historical face passes the 77/77
zero-changed-interior-pixel baseline check, and an exhaustive stress fixture
simultaneously changes the mapped fields on all 77 cards under strict source
mode. The field audit classifies all 892 editor field instances with zero
unknowns, while the finite-state matrix strict-renders all 1,015 declared patch
states. Metadata such as deck limit and keywords is versioned but not printed;
side, faction, uniqueness, and type are labelled frame-defining before editing.
A text value that cannot fit or unavailable finite value still fails closed to
the visibly different Forge community frame.

When this legacy path is explicitly enabled, its UI and print sheet label the
output as a private modified proxy without covering the card face. The official
PnP faces do not become editable art layers; the reconstructed line is
explicitly not an NSG production source file. This repository does not claim
permission to publish or redistribute altered NSG faces.
