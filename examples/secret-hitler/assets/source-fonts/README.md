# Editable title fonts

Forge uses these bundled, open-licensed fonts only for newly edited text over
the CC BY-NC-SA 4.0 Secret Hitler print-and-play faces:

- **Germania One** — SIL Open Font License 1.1. It is a redistributable
  approximation for the original outlined display lettering; the original
  artwork appears unchanged until a mapped title is edited.
- **Barlow Condensed Bold** — SIL Open Font License 1.1. Used for editable
  condensed placard lettering.

The corresponding `OFL-*.txt` files are the license texts distributed by the
Google Fonts repository. The fonts and the original Secret Hitler artwork keep
their own licenses and attribution; bundling one does not relicense the other.
