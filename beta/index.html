The CLI

Everything the site does, offline, on your machine. Apache-2.0.

# get it
git clone https://github.com/YOUR-ORG/YOUR-REPO && cd YOUR-REPO && npm install

# your spreadsheet → a validated, versioned game
npx fmt import csv mycards.csv my-game --title "My Game"
npx fmt validate my-game

# print it, play it, ship it
npx fmt export pnp my-game        # print-and-play PDF
npx fmt export tts my-game        # Tabletop Simulator mod
npx fmt save my-game              # commit — the message writes itself
npx fmt stats my-game             # cost curve, flagged cards, decision trail

Open by design

The format is the product — and it's yours.

Schemas and tools are Apache-2.0; the spec and example game are CC0. Card data round-trips to CSV and InDesign, so leaving is always easy — which is exactly why you can trust staying. Communities like Null Signal Games and the ArkhamDB family already maintain their games as version-controlled data; this is the standard and tooling that workflow deserved.

Beta status: the format is v0.1 (breaking changes possible until v1.0, with migrations). The hosted playground resets nightly. Found something broken or missing? That's the point of a beta — tell us.
